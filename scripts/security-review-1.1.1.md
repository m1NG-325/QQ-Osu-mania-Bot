# 1.1.1 安全审查记录

审查日期：2026-10-08。此次为定向人工代码审查、依赖漏洞扫描与回归检查，不是独立第三方审计或完整渗透测试。

## 发现与修复

1. **高危：Sharp 0.35.4 的已知漏洞。** GHSA-wq5f-xc86-pv6w 涉及 librsvg 释放后使用，官方指出在特定条件下可在使用 glibc 的 Linux 环境造成远程代码执行。两份项目升级并锁定 Sharp 0.35.5。不能据此认定 Windows 环境曾被利用。
   来源：https://github.com/advisories/GHSA-wq5f-xc86-pv6w
2. **图片下载缺少目标限制。** dan 从 OneBot 图片段或 CQ 字符串取 URL，原逻辑允许任意 HTTP 地址并自动重定向，存在服务端请求内网地址的边界缺口。现在仅允许 qpic.cn、qlogo.cn、multimedia.nt.qq.com 及其子域名，拒绝凭据和非标准端口；最多三次重定向，每一跳重新校验。受信 OneBot API 返回的本地图片文件仍可读取。
3. **谱面数据校验不完整。** 原逻辑只限制音符头时间，没有全面限制结束时间和轨道数据。两类分析 worker 现在统一检查数组长度、最多 50000 音符、头尾时间在两小时范围内、结束不早于开始，以及合法轨道和类型，异常数据在估算前被拒绝。

## 审查范围与证据

- 4K LN 适配层、贡献曲线、估算 worker、固定本地导入的 ManiaTracker 算法模块；未在此次新增算法模块发现动态执行、网络传输或文件访问。
- 本地 SVG 素材、图片下载和 Python 合成服务的输入大小与处理限额。
- OneBot 身份校验、群范围、发布目录既有资源预算与取消机制；保留发布项目独立安全修复。
- 两份 npm lockfile 的生产依赖扫描均为 0 个已知漏洞。该结果仅代表扫描时数据库覆盖的依赖问题，不覆盖所有 Python/native 漏洞。
- 新增安全回归覆盖私有地址、伪装域名、凭据/端口、跨域重定向、受信 CDN 重定向、异常结束时间及实际 worker 拒绝行为。集成测试覆盖用户 CQ 内网 URL 被拒绝，以及受信 OneBot 本地文件合成。

## 发布状态

1.1.0 发布前运行了功能与既有安全回归，但未完成本次专项审查，也遗漏了新披露的 Sharp 漏洞。1.1.1 修复同步至运行项目与 GitHub 上传项目；原 GitHub 1.1.0 标签与文件保持原样，新发布需用户确认公告后执行。

4. **回复图片的群归属校验缺口。** 原判断接受没有 group_id 的 get_msg 返回值，无法排除私聊图片。现在要求当前事件与目标消息均有群号且严格匹配。新增无群号、跨群和同群消息回归。该缺口的利用还依赖攻击者知道或猜中可由机器人读取的消息 ID，未确认实际泄漏。

## 四份版本的个人信息复核

复核当前本地 1.1.1、GitHub 实际发布的 0.4.1 / 1.0.0 / 1.1.0 下载包、对应标签及全部 Git blob 历史。三个发布包分别为 370、373、423 个文件，未发现 .env、绑定/历史/日志/缓存目录，未匹配本机真实令牌、已配置群号、绑定 QQ 号、用户目录路径或常见密钥格式。提交署名使用 GitHub noreply 邮箱；GitHub 用户名属于公开身份。此项扫描不等于证明不存在任何未识别的个人信息或历史入侵。

三个旧标签均包含没有群号仍可用于回复取图的判断，以及未限制图片目标地址的下载逻辑。利用前者需要获知或猜中机器人可读取的消息 ID；当前修复要求消息明确属于当前群。没有证据表明这些缺口已被利用。

本机 bot 与 OneBot HTTP API 分别只监听 127.0.0.1:3210 / 127.0.0.1:3000。NapCat 管理面板监听所有网卡的 6099 端口，设有非已知默认值密码，QQ 入站防火墙规则允许公用及专用网络；其可达性仍取决于实际网络和规则范围，不能断言已向互联网开放。管理面板配置未修改。

推荐查询向 ManiaTracker 发送被查询玩家的公开 osu! ID；不会在该请求中附带 QQ 号、群号、绑定记录或 osu! OAuth 凭据。第三方服务会接收网络请求及连接源 IP，这属于该查询功能的正常数据流。
